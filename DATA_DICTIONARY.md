# Data Dictionary

**Observation Unit:** one Valorant round.

| Field | Meaning | Suggested Values |
|---|---|---|
| observation | Observation number | 1, 2, 3... |
| date | Date played | YY-MM-DD |
| map | Valorant game map | text |
| agent | Agent played that game | text |
| result | Match outcome | Win / Loss |
| kills | Kills in game | integer |
|deaths | Deaths in game | integer |
| musicPlaying | Was music playing? | Yes / No |
| musicGenre | What genre? | R&B, Pop, Rap, Other, None |
| musicEnergy | How hyper did the music make me | 1-5; use 0 if no music |
| moodBefore | My mood before the game | 1-5 |
| moodAfter | My mood after the game | 1-5 |
| genderVisible | Was my gender relevant in the game / the interactions? | Yes / No |
| interaction | Rating the interaction | None / Neutral / Positive / Negative |
| socialExperience | My rating of the overall social experience | 1-5 |
