# SCAMPER Development Notes for the Dear Data 100 project

## Substitute
Make a more expressive visual object instead of a more conventional chart

## Combine
How to combine gaming, music, mood and social-experience variables in one visual object so that it makes sense and not be unreadable?

## Adapt
Can I find inspiration in gaming interfaces, music visuals, timelines or diaries' visual languages for the project?

## Modify
What parts of the data could I change in size, colour, shape, movement, texture or repetition?

## Put to another use
Can a musical characteristic be encoded from textual to visual

## Eliminate
What is unnecessary and doesn't need to be put into the dataset? Could be variables, visual elements or information.

## Reverse / Rearrange
Different stories could be revealed depending on differences in chronological, mood-based, music-based, or interaction-based arrangements.

## Reflection on completed project future prompts
- What did I predict before collecting the data?
- What patterns surprised me?
- Which visual characteristic communicated the best?
- What did I reject in the process of the project and why?
- How did the design change as the dataset grew in number?
